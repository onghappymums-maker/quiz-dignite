Politique de Confidentialité

Quiz Dignité by ONG Happy Mum's
Dernière mise à jour : Mai 2026

Quiz Dignité est une application éducative gratuite développée par ONG Happy Mum's, organisation ivoirienne engagée pour la dignité menstruelle et les droits des filles.

1. Données collectées

Lors de votre première utilisation, l'application vous demande :

  • Votre prénom
  • Votre pays

Ces informations sont nécessaires pour personnaliser votre expérience et enrichir nos données analytiques afin de mieux comprendre notre audience et améliorer continuellement l'application. Elles sont collectées une seule fois et mémorisées sur votre appareil.

2. Stockage des données

Toutes vos données (prénom, pays, scores, badges, progression) sont stockées uniquement sur votre appareil via le stockage local du navigateur (localStorage). Vos données ne quittent jamais votre téléphone ou ordinateur.

3. Données analytiques (Google Analytics 4)

Nous utilisons Google Analytics 4 pour mesurer l'audience de l'application. Les données suivantes sont transmises de manière anonyme :

  • Le prénom saisi (pour personnaliser les rapports d'usage)
  • Le pays déclaré (pour analyser la répartition géographique)
  • Les sections et catégories utilisées
  • Les scores obtenus de façon agrégée

Ces données nous permettent de mesurer l'impact éducatif de l'application. Elles ne sont jamais revendues à des tiers.

4. Protection des mineurs

Quiz Dignité s'adresse notamment aux jeunes à partir de 10 ans :

  • Aucun compte utilisateur n'est créé
  • Aucun paiement n'est requis
  • Aucune publicité n'est affichée
  • Aucune donnée sensible n'est collectée

5. Vos droits

  • Supprimer vos données en vidant le cache de votre navigateur
  • Utiliser l'application en mode navigation privée
  • Nous contacter pour toute question
